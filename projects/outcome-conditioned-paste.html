Outcome-Conditioned PASTE for LLM-Based Agents

Active research, 2026

Research question

Can we infer what a request should ultimately accomplish, then use that endpoint to predict tool calls more accurately than PASTE or experience-based retrieval?

Background and motivation

Speculative tool calling, and later PASTE and B-PASTE, exist to make tool execution more efficient by predicting tool calls from the token stream before the model emits them. Li et al. (2026) show in Speculate with Memory that incorporating historical trajectories, through spaced retrieval and prediction-error feedback, improves speculative tool-calling accuracy.

We aim to extend this approach by organizing prior experience around inferred end-goals, then using those goals to distinguish between plausible continuations of an observed workflow.

The hypothesis: similar execution inputs can lead to different outcomes. Explicitly representing the intended outcome should improve the selection of relevant trajectories beyond what contextual similarity alone achieves, with gains in both execution speed and task accuracy.

Design overview

We combine an outcome-conditioned adaptation of Salesforce's speculative predictor with a PASTE-based execution runtime. The pipeline has four stages.

  1. Infer the objective. From the query, application policy, and interaction history, infer the requested outcome and its completion constraints. Where the evidence is ambiguous, maintain multiple candidate objectives rather than committing to one.
  2. Retrieve and predict. Condition Salesforce-style retrieval on those objectives, comparing the current trajectory against a goal-oriented task repository to surface relevant workflow patterns and candidate calls that resolve outstanding prerequisites. The repository is initialized from Salesforce's APIGen-MT-5k: 5,000 synthetic multi-turn executions across retail and airline tasks.
  3. Schedule speculative execution. Pass the selected candidates to a PASTE-based scheduler that prioritizes and launches calls before the primary agent requests them, retaining PASTE's admission criteria: resolved arguments, prediction confidence, expected latency benefit, and available resources.
  4. Feed results forward. The agent receives the retrieved patterns and speculative observations before selecting its next action. This deliberately departs from the original frameworks, which withhold speculative results until invocation matching, so that observations improve decisions rather than only accelerate them. Subsequent observations update the objective hypotheses; consequential actions remain subject to authorization.

Evaluation

Prediction quality is evaluated on τ²-bench and WebArena using fixed-execution replay, following Li et al., before measuring realized speedups through live execution.

  • Primary outcomes: task success, repeated-run reliability, and independently assessed constraint violations.
  • Goal attainment: measured against held-out task specifications.
  • Latency: tool execution latency compared against the base agent and PASTE.
